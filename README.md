# tool_chat_archive_viewer
チャットソフト系からエクスポートしたチャットログファイルを、日時で整理して見やすい形で表示するビューア。エクスポート済みのファイルを与えられることを前提とし、チャットソフト等のデータやりとりや操作は行わない。

当初は完全ローカル動作で作成し、Slackのログに対応したローカル動作完成版が [このタグ](https://github.com/suusanex/tool_chat_archive_viewer/releases/tag/v1_offline_only) です。

その後、特定用途限定でAzure Storageからファイルをダウンロードして読む機能を追加しています。（設定を追加した場合にだけ動作する内輪向け機能、説明なし）
